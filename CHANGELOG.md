# Changelog

Beta builds and stable releases are tracked separately. A beta entry describes a test build; stable entries are kept when a production release is published.

## Beta builds

### 1.0.0-beta.7 — 2026-11-10

- Replaced manual video importing on mobile with automatic device-library scanning, paged loading, thumbnails, and limited-permission support.
- Simplified the home screen around the local video library, with search, favorites, portrait/landscape filters, recent playback, and optional WebDAV access.
- Improved portrait and landscape playback: the inline player follows the video's aspect ratio, fullscreen follows the video's orientation, and a rotation control lets users switch orientation.
- Added the beta's feature notes to its GitHub Release description.

### 1.0.0-beta.6 — 2026-11-10

- Added a persistent local media library with multi-file import, search, video/audio filters, sorting, favorites, and media details.
- Added resume prompts with saved playback positions, configurable skip intervals, auto-next, and queue/current-item repeat modes.
- Added horizontal drag seeking, double-tap seeking, long-press 2x playback, and right-side vertical volume gestures.
- Added external SRT/VTT subtitles with half-second timing adjustments and configurable subtitle size.
- Added Android `content://` playback support for files selected through the system picker.

### 1.0.0-beta.5 — 2026-11-10

- Reworked the app around a phone-first local video library, with WebDAV kept as an optional source.
- Added multi-file playback queues, recent local files, and desktop folder scanning.
- Added fullscreen landscape playback, immersive system bars, progress seeking, previous/next, 10-second jumps, speed control, fit modes, control locking, and a sleep timer.
- Added persistent settings for fullscreen behavior, control visibility, default speed, and local playback history.
- Rebuilt the Android APK with the same release signing certificate as Beta 4.

### 1.0.0-beta.4 — 2026-11-10

- Switched Android beta builds to a persistent signing certificate so future beta updates can install over this build.
- Improved the local-first library and Android release compatibility.
